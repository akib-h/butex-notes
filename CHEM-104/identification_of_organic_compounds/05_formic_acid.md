# Formic Acid (HCOOH) — Identification

## Physical Properties

* Colourless, pungent-smelling, hygroscopic liquid.
* B.P. = 100 °C.
* Soluble in all proportions in water, ethanol, and ether.
* Irritating to the mucous membrane of the eyes.
* Structurally unique among carboxylic acids: it contains both –COOH and an aldehyde-like –CHO character in the same molecule, so it also behaves as a reducing agent.

## Tests

### (i) NaHCO₃ Test

HCOOH + NaHCO₃
→ HCOONa + CO₂ + H₂O

**Observation:** Brisk effervescence of CO₂ gas.

**Reaction:**

$$\ce{HCOOH + NaHCO3 -> HCOONa + CO2 ^ + H2O}$$

### (ii) Conc. H₂SO₄ Test

HCOOH + a small amount of conc. H₂SO₄, warm
→ CO + H₂O (+ H₂SO₄ unchanged)

**Observation:** Effervescence of CO gas.

**Reaction:**

$$\ce{HCOOH ->[conc. H2SO4][\Delta] CO ^ + H2O}$$

### (iii) Fehling's Solution Test

HCOOH + Fehling's solution, warm
→ Cu₂O (red ppt.) + Na₂CO₃ + H₂O

**Observation:** Brick-red precipitate of cuprous oxide.

**Inference:** Positive — confirms the hidden aldehyde-like reducing character of formic acid; **this test is negative for all other carboxylic acids in this syllabus.**

### (iv) KMnO₄ Test

KMnO₄ + a small amount of dilute H₂SO₄ + HCOOH
→ discharge of KMnO₄'s purple colour

**Observation:** Purple colour of KMnO₄ fades.

**Reaction:**

$$\ce{2KMnO4 + 3H2SO4 -> K2SO4 + 2MnSO4 + 3H2O + 5[O]}$$
$$\ce{5HCOOH + 5[O] -> 5CO2 + 5H2O}$$

### (v) Tollens' Reagent Test

HCOOH + Tollens' reagent, warm gently
→ silver mirror

**Observation:** Bright silver mirror deposits on the inner wall of the test tube.

**Reaction:**

$$\ce{2Ag(NH3)2OH + HCOOH -> 2Ag v + (NH4)2CO3 + 2NH3 + H2O}$$

## Comparison Note

Formic acid is the **only** carboxylic acid in this syllabus that gives positive Tollens'/Fehling's tests — see [06_acetic_acid.md](06_acetic_acid.md) for the contrast (negative on both).
