# Acetic Acid (CH₃COOH) — Identification

## Physical Properties

* Colourless, pungent, vinegar-like liquid.
* B.P. = 118 °C.
* Glacial acetic acid freezes near 16.6 °C (ice-like crystals).
* Miscible with water in all proportions.

## Tests

### (i) NaHCO₃ Test

CH₃COOH + NaHCO₃
→ CH₃COONa + CO₂ + H₂O

**Observation:** Brisk effervescence of CO₂ gas.

**Reaction:**

$$\ce{CH3COOH + NaHCO3 -> CH3COONa + CO2 ^ + H2O}$$

### (ii) Tollens'/Fehling's Test

CH₃COOH + Tollens'/Fehling's reagent, warm
→ **no reaction**

**Observation:** No silver mirror, no red Cu₂O ppt.

**Inference:** Negative — distinguishes acetic acid from formic acid, which gives a positive result on both.

### (iii) Esterification Test

CH₃COOH + C₂H₅OH + conc. H₂SO₄, warm
→ ethyl acetate + H₂O

**Observation:** Sweet, fruity smell.

**Reaction:**

$$\ce{CH3COOH + C2H5OH ->[conc. H2SO4][\Delta] CH3COOC2H5 + H2O}$$

### (iv) Ferric Chloride Test

Neutralise CH₃COOH solution first, then add neutral FeCl₃, boil
→ deep red colour, which fades to a reddish-brown precipitate (basic ferric acetate) on boiling

**Observation:** Deep red colouration, then flocculent reddish-brown precipitate on prolonged boiling.

**Inference:** Characteristic of the acetate ion.
