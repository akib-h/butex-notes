# Formaldehyde (HCHO) — Identification

## Physical Properties

* Pungent, colourless gas; commercially handled as ~37–40% aqueous solution ("formalin").
* Very soluble in water.
* Irritating to eyes and mucous membranes.

## Tests

### (i) Tollens' Reagent Test

HCHO + Tollens' reagent, warm gently
→ silver mirror

**Observation:** Bright silver mirror on the tube wall.

**Reaction:**

$$\ce{HCHO + 2Ag(NH3)2OH -> 2Ag v + HCOONH4 + 3NH3 + H2O}$$

### (ii) Fehling's Solution Test

HCHO + Fehling's solution, warm
→ brick-red Cu₂O precipitate

**Observation:** Red precipitate of cuprous oxide.

### (iii) Schiff's Reagent Test

HCHO + Schiff's reagent (decolourised fuchsin)
→ pink/magenta colour restored

**Observation:** Pink colour develops, confirming an aldehyde.

### (iv) Iodoform Test

HCHO + I₂ + NaOH, warm
→ **negative** — no yellow precipitate

**Inference:** No CH₃CO– group present; formaldehyde has only one carbon.

### (v) 2,4-DNP Test

HCHO + 2,4-dinitrophenylhydrazine reagent
→ yellow/orange precipitate (hydrazone)

**Observation:** Yellow-orange crystalline precipitate confirms a carbonyl group.
