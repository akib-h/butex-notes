# Acetone (CH₃COCH₃) — Identification

## Physical Properties

* Colourless, volatile liquid with a sweetish odour.
* B.P. = 56 °C.
* Miscible with water in all proportions.

## Tests

### (i) Tollens'/Fehling's Test

Acetone + Tollens'/Fehling's reagent, warm
→ **no reaction**

**Observation:** No silver mirror, no red Cu₂O ppt.

**Inference:** Confirms acetone is a ketone, not an aldehyde — there is no hydrogen on the carbonyl carbon, so it cannot be oxidised/act as a reducing agent the way an aldehyde does.

### (ii) Iodoform Test

Acetone + I₂ + NaOH, warm
→ **yellow precipitate** of iodoform

**Observation:** Yellow crystalline ppt., antiseptic smell.

**Reaction:**

$$\ce{CH3COCH3 + 3I2 + 4NaOH -> CHI3 v + CH3COONa + 3NaI + 3H2O}$$

### (iii) 2,4-DNP Test

Acetone + 2,4-DNP reagent
→ yellow precipitate (hydrazone)

**Observation:** Confirms the carbonyl group.

### (iv) Schiff's Reagent Test

Acetone + Schiff's reagent
→ **no colour** (or extremely faint/slow)

**Observation:** Distinguishes ketone from aldehyde.

### (v) Sodium Nitroprusside Test

Acetone + sodium nitroprusside + NaOH
→ red colour

**Observation:** Confirmatory colour test specific to methyl ketones.
