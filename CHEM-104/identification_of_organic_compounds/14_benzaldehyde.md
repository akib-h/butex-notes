# Benzaldehyde (C₆H₅CHO) — Identification

## Physical Properties

* Colourless to pale-yellow oily liquid with a bitter-almond smell.
* B.P. = 178 °C.
* Aromatic aldehyde with **no α-hydrogen** — this single structural fact explains most of its unusual test results below.

## Tests

### (i) Tollens' Reagent Test

C₆H₅CHO + Tollens' reagent, warm gently
→ silver mirror

**Observation:** Silver mirror forms — confirms an aldehyde group.

### (ii) Fehling's Solution Test

C₆H₅CHO + Fehling's solution, warm
→ **weak or no reaction**

**Observation:** Little to no red Cu₂O ppt.

**Inference:** Aromatic aldehydes are generally poor Fehling reducers, unlike aliphatic aldehydes — this is a key distinguishing feature from acetaldehyde/formaldehyde.

### (iii) Iodoform Test

C₆H₅CHO + I₂ + NaOH, warm
→ **negative**

**Inference:** No CH₃CO– or CH₃CH(OH)– grouping is present.

### (iv) Cannizzaro Reaction

C₆H₅CHO + conc. NaOH (no α-H available)
→ disproportionates to benzyl alcohol + sodium benzoate

**Reaction:**

$$\ce{2C6H5CHO + NaOH -> C6H5CH2OH + C6H5COONa}$$

**Inference:** Confirmatory for an aldehyde with no α-hydrogen — it cannot undergo aldol condensation, so it self-oxidises/reduces instead.

### (v) 2,4-DNP Test

C₆H₅CHO + 2,4-DNP reagent
→ yellow precipitate

**Observation:** Confirms the carbonyl group.
