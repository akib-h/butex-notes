# Phenol (C₆H₅OH) — Identification

## Physical Properties

* Colourless to pink crystalline solid with a characteristic sharp smell.
* M.P. = 40–41 °C.
* Corrosive to skin — causes chemical burns; handle with gloves.

## Tests

### (i) Neutral Ferric Chloride Test

Phenol solution + neutral FeCl₃
→ **violet/purple colour**

**Observation:** Deep violet colouration.

**Inference:** Classic confirmatory colour test for a phenolic –OH group.

### (ii) Bromine Water Test

Phenol + bromine water
→ white precipitate of 2,4,6-tribromophenol

**Observation:** White precipitate forms immediately.

**Reaction:**

$$\ce{C6H5OH + 3Br2 -> C6H2Br3OH v + 3HBr}$$

### (iii) NaOH Solubility Test

Phenol + NaOH solution
→ dissolves readily (forms sodium phenoxide)

**Observation:** Clear solution forms.

**Inference:** Confirms the acidic (though weak) –OH group.

### (iv) NaHCO₃ Test

Phenol + NaHCO₃
→ **no effervescence**

**Observation:** No gas evolved.

**Inference:** Phenol is too weak an acid to liberate CO₂ from bicarbonate — this is the key test that distinguishes phenol from carboxylic acids.

### (v) Liebermann's Nitroso Reaction

Phenol + NaNO₂/conc. H₂SO₄, then dilute with water, then add excess NaOH
→ blue-green colour, red on dilution, changes further on addition of alkali

**Observation:** Sequence of colour changes is confirmatory for phenols.

## Comparison Note

See [10_picric_acid.md](10_picric_acid.md) — picric acid is a phenol too but, unusually, gives NaHCO₃ effervescence and fails the FeCl₃ violet test, exactly the reverse of ordinary phenol.
