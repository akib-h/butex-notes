# Nitrobenzene (C₆H₅NO₂) — Identification

## Physical Properties

* Pale yellow oily liquid with an almond/shoe-polish-like smell.
* B.P. = 211 °C.
* Denser than water — forms a bottom layer when shaken with water.

## Tests

### (i) Reduction Test (followed by Carbylamine Test)

Nitrobenzene + Sn (or Fe) + conc. HCl, warm
→ aniline + H₂O

**Reaction:**

$$\ce{C6H5NO2 + 6[H] ->[Sn/HCl] C6H5NH2 + 2H2O}$$

Then take the product and run the carbylamine test (product + CHCl₃ + alcoholic KOH, warm):
→ foul carbylamine smell

**Observation:** Foul odour confirms the reduction product is a primary amine (aniline).

**Inference:** Confirms that the original nitrogen was present as –NO₂, since it took reduction to reveal amine character.

### (ii) Mulliken–Barker Test

Nitrobenzene + SnCl₂/NH₄OH, followed by treatment with freshly prepared cuprous chloride
→ blue colouration

**Observation:** Blue colour develops — a standard qualitative confirmatory test for the nitro group.

### (iii) Physical/Density Test

Shake sample with water, observe layering.
→ oily nitrobenzene layer sinks **below** the water layer

**Observation:** Denser-than-water oily layer — useful clue during mixture analysis.
