## Group Comparison Tables

### Alcohols

| Property | MeOH | EtOH | iPrOH | tBuOH |
|---|---|---|---|---|
| Class | 1° (only 1 C) | 1° | 2° | 3° |
| Iodoform test | – | + | + | – |
| Lucas test | No reaction (very slow) | No reaction (slow) | Cloudy in 5–10 min | Cloudy instantly |
| Oxidation product | Aldehyde (formaldehyde) | Aldehyde (acetaldehyde) | Ketone (acetone) | No oxidation |

Lucas test rate order comes from SN1 carbocation stability: 3° > 2° > 1°.

### Carboxylic Acids

| Property | Formic | Acetic | Oxalic | Benzoic | Salicylic | Picric |
|---|---|---|---|---|---|---|
| Tollens'/Fehling's | **Positive** | Negative | Negative | Negative | Negative | Negative |
| NaHCO₃ effervescence | Yes | Yes | Yes | Yes | Yes | Yes (unusual for phenol) |
| FeCl₃ (neutral) | — | Red, fades | — | pale/buff ppt | **Violet** | No colour |
| State | Liquid | Liquid | Solid | Solid | Solid | Solid, yellow |
| Distinctive extra group | –CHO character | none | diacid | aromatic | phenolic –OH | 3× –NO₂ |

### Carbonyl Compounds

| Property | Formaldehyde | Acetaldehyde | Acetone | Benzaldehyde | Acetophenone |
|---|---|---|---|---|---|
| Class | Aldehyde | Aldehyde | Ketone | Aromatic aldehyde | Aromatic ketone |
| Tollens'/Fehling's | + | + | – | Tollens +, Fehling weak/– | – |
| Iodoform test | – | + | + | – | + |
| Cannizzaro (no α-H) | Yes | No | No | Yes | No |
| 2,4-DNP | + | + | + | + | + |

Decision path: 2,4-DNP positive → carbonyl present → Tollens'/Fehling's → aldehyde vs ketone → iodoform → confirms CH₃CO–/CH₃CH(OH)– unit → Fehling weak + Tollens strong → aromatic aldehyde.

### Miscellaneous Group

| Compound | Diagnostic positive test | Key negative/contrast |
|---|---|---|
| Phenol | FeCl₃ → violet | No NaHCO₃ effervescence (unlike acids) |
| Aniline | Carbylamine test (foul smell) | Only 1° amines give this |
| Nitrobenzene | Reduction → aniline → carbylamine positive | Oily, denser than water |
| Chlorobenzene | Beilstein green flame; AgNO₃ negative directly | Needs fusion to detect Cl as ion |
| Urea | Biuret → violet-pink | NH₃ smell on NaOH |
| Benzamide | NH₃ on NaOH; hydrolysis → benzoic acid | Benzoic acid confirmed via NaHCO₃ |
| Acetanilide | Hydrolysis → aniline + acetic acid | Weak direct NH₃ evolution |
| Acetamide | NH₃ on NaOH; hydrolysis → acetic acid | Deliquescent, very water soluble |
