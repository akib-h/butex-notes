# 01 — Prerequisites

![Level](https://img.shields.io/badge/level-pre--calculus-lightgrey)
![Status](https://img.shields.io/badge/status-complete-brightgreen)

> Calculus doesn't fail because of calculus. It fails because of shaky
> algebra, forgotten trig identities, or a weak grip on what a function
> actually *is*. This folder exists to close those gaps before Chapter 2.

## Why this folder exists

Every single technique in `02-limits/` through `11-vector-calculus/` reduces,
sooner or later, to algebraic manipulation. If you can take a limit but can't
factor the numerator, you don't have a calculus problem — you have an
algebra problem wearing a calculus costume. This folder is a diagnostic and
a refresher, not a full algebra course.

## How to use this folder

Don't read all four files start to finish. Instead:

1. Skim the **Learning objectives** at the top of each file.
2. If you can already do all of them, skip straight to the **Practice
   problems** section and confirm with 3–4 questions.
3. If you get stuck, read only the section of the lesson that covers that
   specific gap.

## Contents

| File | Covers | Skip if you can already... |

| [`algebra.md`](algebra.md) | Factoring, rational expressions, exponent/log rules, solving equations | Factor any quadratic, simplify a rational expression, solve `2^(x+1) = 8` without a calculator |

## Diagnostic checklist

If you answer **no** to any of these, read the corresponding file before
starting Chapter 2 (Limits):

- [ ] Can you factor `x² − 5x + 6` and `x³ − 8` by hand?
- [ ] Can you simplify `(x² − 9)/(x − 3)` and state the excluded value?
- [ ] Do you know `sin(π/6)`, `cos(π/4)`, `tan(π/3)` without looking them up?
- [ ] Can you find the domain of `f(x) = ln(x − 1)`?
- [ ] Do you know why `f(x) = x²` has no inverse function unless its domain
      is restricted?
- [ ] Can you solve `3ˣ = 81` and `log₂(x) = 5` by hand?
